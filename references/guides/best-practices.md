# 最佳实践与故障处理

最后更新：2026-09-01

## 先确认，再写入

始终以 dry-run 开始。检查文件数量、类型、同类顺序和跨类型配对，再生成正式 PDF。任何材料处于待确认状态时停止，不输出“看起来完成”的文件。

## 以票面图像为外观真相

铁路客票、未嵌入字体或显示不稳定的 PDF 必须走截图模式：

```bash
python scripts/layout_expense_documents.py ./sample-input \
  --output ./expense-layout.pdf \
  --render-mode raster \
  --dpi 300
```

不要提取文字后重新绘制，不要为了版面整齐裁掉票面边缘，也不要拉伸到填满槽位。

## 配对规则

- 两个同类型材料优先上下排列。
- 同类型内部先看业务日期，再看开票日期，最后按文件名。
- 只有金额相同或日期相差不超过一天时，才把行程单与交通发票配对。
- 无证据的单张材料只放上半页，下半页留空。

## 源文件与回滚

- 不覆盖、不重命名、不移动输入文件。
- 生成前后比较源文件 SHA-256。
- 先写临时文件，验证后再原子替换为最终结果。
- 验证失败时删除临时结果，保留全部输入。

## 打印

生成 PDF 和提交打印任务是两个动作。用户明确要求打印后，再由宿主检查实际打印机能力。默认意图是一份、A4、单面、黑白；无法确认某项设置时应报告限制。

## 性能建议

- 常规文档使用 `auto`，只对风险页截图，可减小输出体积。
- 300 DPI 适合一般打印；更高 DPI 会显著增加内存和文件大小。
- 大批量材料按报销批次拆分目录，便于核对和回滚。
