# 分类规范

最后更新：2026-09-01

## 类型

| 类型 | 主要证据 | 输出用途 |
|---|---|---|
| `railway-ticket` | 铁路电子客票标题或明确文件名 | 强制截图保真 |
| `accommodation-invoice` | 住宿费、住宿服务 | 同类配对 |
| `transport-invoice` | 交通运输、客运、出租车服务 | 同类或关联行程单 |
| `itinerary` | 行程单、出行明细 | 关联交通发票 |
| `reimbursement-form` | 费用或差旅报销单 | 关联发票 |
| `general-invoice` | 只有通用发票证据 | 同类配对 |
| `unclassified` | 无证据或最高分并列 | 停止并请用户确认 |

## 证据优先级

1. 可见正文中的用途关键词。
2. 文件名中的通用用途提示。
3. 页面比例和字体风险只辅助渲染，不改变业务类型。

发票开具方、报销单位和人员姓名不是分类条件。

## 正确与错误示例

正确：正文包含“住宿费”时归入住宿发票，即使文件名只有流水号。

错误：因为某个单位名称曾经出现在住宿发票中，就把同单位的全部文件归入住宿类型。原因是单位名称不能说明本张材料的用途。

## 人工覆盖

仅在用户看过原件并确认后使用 `type_overrides`。覆盖按文件 basename 精确匹配，并记录为配置证据。覆盖不能改金额、日期或票面内容。
