# Changelog

All notable changes follow Semantic Versioning.

## Unreleased

### 2026-11-24

- Ask whether to print when delivering the verified A4 PDF. A clear confirmation or an existing print instruction authorizes printing the same PDF.
- Check printer options before submission and verify the job status afterward. Default to one copy, A4, single-sided, monochrome.

## [1.0.0] - 2026-09-01

- Added issuer-neutral reimbursement document classification.
- Added same-type-first grouping and evidence-based cross-type pairing.
- Added portrait A4 two-slot layout with proportional scaling.
- Added 300-DPI raster preservation for railway tickets and font-risk PDFs.
- Added source-hash validation, privacy-safe manifests, dry-run, documentation, and cross-platform tests.
