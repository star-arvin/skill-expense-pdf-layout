# 报销材料分类与 A4 拼版使用指南

版本：1.0.0  
最后更新：2026-09-01

## 适用场景

本技能用于把本地报销材料整理成便于 A4 打印的 PDF。它适合两张同类发票上下拼版、铁路电子客票截图保真、有关联证据的行程单与发票配对，以及最后一张材料单独占上半页。

## 触发方式

常见表达包括：

- “把这个文件夹的报销材料整理成 A4。”
- “一页放两张电子发票，上下排列。”
- “铁路客票只截图，不要重建文字。”
- “先预览分类，确认后再生成。”

## 输入与输出

| 项目 | 内容 |
|---|---|
| 输入 | 一个只包含本批 PDF、PNG、JPEG 的本地目录 |
| 可选输入 | YAML 类型覆盖配置、DPI、渲染模式 |
| 输出 | 新的纵向 A4 PDF |
| 附加输出 | 隐私安全的 JSON 映射清单 |
| 不执行 | 修改源文件、上传材料、填写报销系统、未授权打印 |

## 标准流程

1. 枚举输入并计算源哈希。
2. 识别每页用途；存在未分类、加密或不支持文件时停止。
3. 同类型优先，按日期和文件名排序。
4. 每页最多两个材料，保持比例。
5. 铁路客票和字体风险页按完整图像渲染。
6. 验证 A4、页数、映射和源哈希后写入最终结果。
7. 只有用户明确要求时，再单独处理打印。

## 典型对话

> 用户：先看一下这个目录怎么分组，不要生成文件。
>
> AI：我会运行只读检查和 dry-run，返回每个文件的类型、排序和预期 A4 页码，不写入 PDF。

> 用户：铁路电子客票现在的文字有差异，只按截图排进去。
>
> AI：我会把完整可见页面以至少 300 DPI 渲染为单一图像，等比放入槽位，不提取文字重建票面；完成后验证输出页没有客票文字层。

> 用户：确认分组没问题，生成文件，但不要打印。
>
> AI：我会生成新的 A4 PDF 和映射清单，验证源文件未改变。创建 PDF 与打印相互独立，本次不会提交打印任务。

> 用户：现在打印一份，A4、单面、黑白。
>
> AI：我会先检查宿主可见的打印机和这些选项是否受支持，再提交一份打印任务，并报告实际目标和观察到的任务状态。

> 用户：这张无法识别的扫描件是住宿发票。
>
> AI：我会用文件名精确覆盖为住宿发票，先重新 dry-run；覆盖只改变分类，不改动扫描件内容。

## 注意事项

- `unclassified` 是停止信号，不是可以忽略的警告。
- 不允许从票面文字层重新拼出铁路客票。
- 不允许为了省纸而伪造材料间的关联。
- 公开示例只使用合成数据。
